# Incident Management Service
> A.K.A 'Ima'

Ima is the system's Incident Management service. Ima is in-charge of creating records of incidents on the database for 
registered services and maintaining records of said incidents

## Functionality

Ima's core functionality includes but is not limited to:
* Create incident
* Update incident status
* Auto resolve incidents
* Get all active incidents
* Get incident history
* Resolve Incidents (Manual Operation)
* Close incidents


_Think of Ima like the student academic records_
