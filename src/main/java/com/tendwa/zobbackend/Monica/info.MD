# Monitoring and Canary Service
> A.K.A 'Monica'

Monica's work is simple. Keep a record of canaries. Call these canaries at intervals to find out if they are running as
expected. Keep the results of each call in the database for other services to check against

## Functionality

Monica's core functionality includes but is not limited to:
* Register Canaries
* Run probes
* Get overall service health based on the results of the probes
